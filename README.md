# Cihan City v1.0

iPhone ve masaüstü tarayıcılar için geliştirilen çok dosyalı açık dünya oyun projesi.

## Dosyalar
- `index.html`: Ana sayfa
- `style.css`: Tasarım ve mobil kontroller
- `config.js`: Oyun ayarları
- `utils.js`: Yardımcı matematik fonksiyonları
- `map.js`: Şehir haritası
- `entities.js`: Oyuncu, araç, NPC ve mermiler
- `missions.js`: Görev sistemi
- `ui.js`: Menü, HUD, mağaza ve garaj
- `game.js`: Ana oyun motoru
- `manifest.json`: Ana ekrana ekleme bilgileri

## Güncelleme yöntemi
Bundan sonra yalnızca değişen dosya GitHub'da güncellenecek.
Örneğin araç sistemi değişirse çoğunlukla `entities.js`, görevler değişirse `missions.js` güncellenir.
